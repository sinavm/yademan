# موسیقی یادمان

فایل‌های صوتی را در همین پوشه قرار بده. سپس نام و مسیر هر فایل را به آرایه `tracks` در فایل `playlist.json` اضافه کن.

نمونه:

```json
{
  "tracks": [
    {
      "title": "دود عود",
      "artist": "محمدرضا شجریان",
      "src": "./assets/music/dood-ood.mp3"
    },
    {
      "title": "نی‌نوا",
      "artist": "حسین علیزاده",
      "src": "./assets/music/ney-nava.mp3"
    }
  ]
}
```

- مسیر فایل باید با `./assets/music/` شروع شود.
- فرمت‌های MP3 و M4A و OGG و WAV را می‌توانی استفاده کنی. پشتیبانی نهایی به مرورگر بازدیدکننده بستگی دارد.
- نام فایل‌ها را انگلیسی و بدون فاصله انتخاب کن.
- ترتیب قطعه‌ها در فهرست همان ترتیب دکمه‌های قبلی و بعدی است.
- پلیر بدون کلیک بازدیدکننده هیچ صدایی پخش نمی‌کند.
- فقط فایل‌هایی را بارگذاری کن که اجازه انتشار و پخش عمومی آن‌ها را داری.
